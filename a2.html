A2 inside the current admin panel

Five ways the A2 course can live in the admin panel. Every screen is clickable.

1Course tree“A2” opens the course tree the way a student sees it. Every row keeps its actions in a three-dot menu: Edit, Open, Publish, Delete. A lesson row and Edit on a section open their page inside this frame, a part opens in a small form, and deleting also lives inside the page it belongs to. The Reorder switch turns on dragging, a new order is kept by Save new order or dropped by Cancel; Hide unpublished hides unpublished rows.1.1Edit modeThe same tree, but actions, add buttons and dragging appear only while the Edit mode switch is on: sections and parts show an Edit link instead of the three-dot menu, and a lesson opens by clicking its row. The tree itself has no Delete: a lesson and a section are deleted on their own page, a part in its form. With Edit mode off the tree only expands. Reorder stays a separate switch, as in the first variant.2Hub page“A2” opens a hub page that counts what the course holds; every row opens its list. Lessons, sections, parts, videos, question sets and comments are browsed as flat lists instead of a tree, and a row opens the same lesson or section page as the first two variants.3DropdownThe same six lists, reached from a dropdown of the navbar: Sections, Parts, Lessons · Videos, Lesson Questions · Comments.4TabsThe same six lists, reached from a row of tabs inside a section of its own.
